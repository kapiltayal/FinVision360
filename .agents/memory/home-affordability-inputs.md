---
name: Calculator slider controls
description: Display rule for calculator slider values, tick marks, ranges, and steps.
---

For slider-controlled calculator inputs, show a live value readout without a duplicate numeric input and add evenly spaced tick marks to indicate the available range.

**Why:** The user wants slider ranges to be easier to estimate at a glance while keeping controls uncluttered.

**How to apply:** Bind the slider thumb and visible value to the same state, keep the configured bounds and step, and reserve numeric inputs for fields without sliders. Use a modest number of evenly spaced tick marks across the range.
